# Pokédex

## Autor
Luiz Vinicius Moraes Dos Santos — Matrícula 22609501

## Descrição
Aplicação web que consulta a PokéAPI e exibe os dados de um Pokémon (sprite, tipos, altura, peso, status base e habilidades) a partir do nome ou número digitado pelo usuário.

## API utilizada
- PokéAPI — https://pokeapi.co/docs/v2
- Endpoint consumido: `GET https://pokeapi.co/api/v2/pokemon/{nome-ou-id}`

## Funcionalidades
- Buscar um Pokémon pelo nome ou pelo número da Pokédex
- Ver sprite, número, nome e tipo(s)
- Ver altura, peso e experiência base
- Ver os status base (HP, ataque, defesa, etc.) em barras
- Ver a lista de habilidades
- Mensagem amigável quando o Pokémon não é encontrado ou a API está indisponível
